# Hotel Social Media Banners & Promotional Ad Templates

Owner-supplied doctrine (2026-07-05). Core philosophy: **clarity beats cleverness** — every
pixel communicates spatial value, premium comfort, and a frictionless path to a direct
booking. Scrolling users decide in <1.8 seconds.

## House reconciliation (overrides where the doctrine conflicts)

- **Master palette is OWNER-LOCKED** (2026-07-05): deep walnut/charcoal backgrounds
  (#171310 / #221A12 / #120E0A / #0F0C09), Premium Gold **#D4AF37** accents/frames/hero
  numbers, ivory #F5EFE4 text, muted #B8AD9C secondary. The doctrine's "cool
  teal/slate/emerald for room promos" is **superseded** — teal/green/lime/blue are banned.
  Room and corporate posts stay calm via the walnut+gold neutrals.
- **Warm stimulants ARE allowed as accents** for F&B, rooftop, nightlife and event posts:
  terracotta #C2603D, amber #E8A13C, deep crimson #8E2F2F — always on the walnut base,
  never replacing gold as the primary accent.
- **Fonts in the automated pipeline**: Inter (400/700) + Noto Sans Bengali (৳/Bangla) only —
  Satori renders these. The 2–3 font maximum is therefore enforced by construction.
  Serif/script tiers apply to manually produced assets (Canva/Adobe) only.
- **Real photography only** — the owner's asset library (public `crm-assets/marketing/`
  bucket + fountainbd.com room photos). Never stock clichés, never AI-invented rooms.

## Canvas ratios (renderer supports all three)

| Format | Pixels | Use |
|---|---|---|
| Square 1:1 | 1080×1080 | Grid/carousel/timeline placement |
| **Portrait 4:5 (default for feed ads)** | 1080×1350 | Maximizes mobile screen real estate |
| Story/Reel 9:16 | 1080×1920 | Fullscreen tours, direct-booking pushes — keep **top and bottom ~250px clear** of critical content (native UI overlays) |

Display network sizes (300×250, 728×90, 160×600) are manual-production targets, not pipeline outputs.

## Text & layout rules

- **Headline ≤ 8 words**; total on-image text stays visually under ~20% of the canvas.
  Captions carry the detail; the graphic carries the hook.
- Eye path is architectural: **Hero visual → core value → CTA**, top to bottom.
- Maximum 2–3 typefaces; weight and letter-spacing create hierarchy, not font variety.

## CTA architecture

- 2–5 word action phrases emphasizing value, never friction ("Pay Now" banned):
  **"Book Direct & Save"**, **"Reserve My Room"**, **"Check Corporate Availability"**,
  **"WhatsApp Live Booking"** — always with the number 01322 840 799.
- Chromatic separation: on walnut backgrounds the CTA is a **gold (#D4AF37) container**
  (solid fill with #1C1510 text, or gold-bordered pill on rgba(212,175,55,0.14)) — never a
  floating borderless link.

## Five template archetypes (pick by content type)

1. **Direct Deal** (OFFER / rate posts): hero room photo ~60% of frame; remaining ~40% is a
   clean value panel — bold price badge ("৳4,000/night", "Flat 15% Off Corporate") + large CTA.
2. **Testimonial / Social proof** (real reviews ONLY, from `hotel_settings.marketing_reviews`):
   frosted glass or gold-bordered quote container over a room/lobby photo, star vector row,
   elegant emphasized type.
3. **Asymmetric Bento** (amenity/feature posts): primary photo commands the largest tile;
   smaller tiles for workspace (25+ Mbps), airport proximity (3.2 km HSIA), safe, breakfast.
4. **Local infographic** (travel-guide posts): distance/time metrics mapped airport → lobby;
   clean dot/line motifs; the hotel as the regional authority on convenience.
5. **Event / anticipation** (dining launches, rooftop sessions): dark saturated palette,
   warm gold glow typography, deep shadow masks over real event/rooftop photography —
   warm stimulant accents allowed here.

## Quality control

- Kill any frame whose message can't be absorbed in 1.8 seconds.
- No watermarked photos (the Executive King shot has a burned-in phone watermark — unusable).
- UGC framed inside brand-compliant gold templates outperforms pure polish — balance luxury
  with authentic human proof.
- Cinemagraph/motion variants (subtle cloud drift, lamp-light shift) are a future upgrade
  path for video placements, not a static-pipeline requirement.
